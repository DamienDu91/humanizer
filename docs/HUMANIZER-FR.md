# Humanizer FR

Plugin gratuit de Damien Duguet pour reformuler les textes français et anglais dans ChatGPT tout en préservant leur sens, les faits, les sources et la voix de leur auteur.

Site de Damien Duguet : https://damienduguet.com

Support : https://github.com/DamienDu91/humanizer/issues

Ne publiez pas de données privées dans les Issues. Utilisez un exemple anonymisé.
